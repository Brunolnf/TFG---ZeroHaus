# ZeroHaus

## Reparto de modelos
- Búsquedas y consultas → code-searcher (Haiku)
- Tareas normales del plan → implementer (Sonnet)
- Pagos, autenticación, reglas y seguridad → critical-implementer (Opus xhigh)
- Ejecutar tests → test-runner (Haiku)
- Revisión antes del merge → reviewer (Opus). El modelo que escribió el código nunca lo revisa.
- Planificar, auditar y decidir → sesión principal (Fable)
